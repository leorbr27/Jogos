# Treino Visual 50

Jogo de atenção visual com 50 números aleatórios, tabuleiro circular em rotação contínua e cronômetro de 60 segundos. Funciona em celulares e computadores, sem login, banco de dados ou bibliotecas externas.

## Publicar esta pasta no GitHub Pages
Como o jogo está dentro de uma subpasta de `Jogos`, o Pages padrão publica a raiz do repositório e não necessariamente essa subpasta como site independente. Para usar o jogo, habilite Pages para o repositório e acesse a pasta pelo caminho correspondente; alternativamente, configure uma publicação específica da pasta com GitHub Actions.
